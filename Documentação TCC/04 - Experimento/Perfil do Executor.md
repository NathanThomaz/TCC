# Perfil do Executor (D2)

Fonte: [perfil-executor.md](https://github.com/NathanThomaz/TCC/blob/main/docs/perfil-executor.md) · Decisão [[Decisões Metodológicas#D2. Perfil do executor|D2]] — **PENDENTE**

Preencher **uma vez, antes do piloto**, no arquivo do repositório. Caracteriza o participante no capítulo de metodologia e ajuda a interpretar a validade externa. **Sem dados sensíveis** (o repo é público).

**Situação (28/10/2026):** formulário criado, **todas as respostas em branco**. Identificador já definido: **E01** (também em `experimento.toml` → `[executor]`).

## Itens do formulário
- Formação (curso, período)
- Experiência profissional com desenvolvimento (anos)
- Experiência com Python (anos; nenhum / acadêmico / profissional)
- Experiência com SQL (anos; uso)
- Experiência com testes automatizados (pytest ou similar)
- Ferramentas de IA para programação já usadas (quais, por quanto tempo)
- Frequência de uso de IA para programar antes do estudo (nunca / mensal / semanal / diária)
- Ferramenta da condição B: tempo prévio de uso
- Editor/IDE habitual
- **Expectativa ANTES do estudo:** a IA vai te deixar mais rápido? (% estimado)
- **Expectativa ANTES do estudo:** a IA vai melhorar a qualidade? (1–5)

> As duas expectativas precisam ser registradas **antes** de qualquer sessão. Depois serão comparadas com o resultado medido (cf. Becker et al., 2025: divergência entre expectativa e medição).
