# Registro de trabalho

Controle do que foi **solicitado**, **feito** e **respondido** em cada interação de trabalho no TCC. Cada entrada é um arquivo numerado, em ordem cronológica, e nunca é apagada. Correções entram como entradas novas.

**Formato de cada entrada:**
1. **Solicitado:** resumo fiel do pedido.
2. **Feito:** ações executadas.
3. **Resposta:** retorno entregue, com resultados reais.
4. **Arquivos:** criados, alterados ou removidos.
5. **Pendências.**
